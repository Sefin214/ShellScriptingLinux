Topic 1: Constructs (if, else, elif)
Q1. Create a script that takes a number from the user and checks whether it is positive, 
negative, or zero.
Hint: 
Use if [ $num -gt 0 ] for checking positive numbers and elif for the other conditions.
Q2. Write a script that asks for a user's age. If the age is 18 or older, print "Eligible to vote", 
otherwise print "Not eligible".
Hint: 
Use the -ge (greater than or equal to) operator inside your conditional brackets.
Q3. Develop a script that checks if a specific file named report.txt exists in the current 
directory. If it does, print "File found", otherwise print "File missing".
Hint: 
Use the -f flag inside the if condition to check for regular file existence.
Q4. Create a script that accepts a filename from the user and checks if the file has read 
permissions enabled for the current user.
Hint: 
Use the -r flag inside your if statement to test read permissions.
Q5. Write a script that asks the user to enter a string and checks if the entered string is empty 
or not.
Hint: 
Use the -z operator to check if the length of a string is zero.
Q6. Create a script that asks the user for a username. If the username is "admin", print 
"Access Granted", otherwise print "Access Denied".
Hint: 
Use the = operator to compare strings inside [ ] or [[ ]].
Q7. Write a script that checks if a directory named backup exists. If it does not exist, create 
the directory using mkdir.
Hint: 
Combine the ! (not) operator with the -d flag to check if a directory is missing.
Q8. Create a script that compares two numbers entered by the user and prints which one is 
greater, or if they are equal.
Hint: 
Use -gt, -lt, and -eq for comparing integers.
Q9. Write a script that checks if the current year is a leap year. (Assume the year is 
hardcoded or read from the user).
Hint: 
A year is a leap year if it is divisible by 4 but not by 100, or divisible by 400. Use the % 
arithmetic operator inside (( ... )).
Q10. Create a script that asks for a numerical exam score (0-100) and prints the 
corresponding grade: A (>=90), B (>=80), C (>=70), or F (<70).
Hint: 
Use a chain of if, elif, and else statements checking the score from highest to lowest.
Q11. Write a script that asks the user for a password. If the password matches "Secret123", 
print "Welcome", otherwise print "Wrong Password".
Hint: 
Use string comparison syntax: if [ "$password" == "Secret123" ].
Q12. Create a script that checks if a file is empty (has a size of 0 bytes) and deletes it if it is 
empty.
Hint: 
Use the -s operator, which checks if a file exists and has a size greater than zero; you want 
the opposite (! -s).
